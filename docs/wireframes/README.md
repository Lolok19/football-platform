# Wireframes Red Corner

Это цифровой текстовый прототип (вариант В лабораторной работы). Каждый экран описан через назначение, блоки, доступ и источник динамических данных. Фактическая интерактивная реализация находится в `src/views/index.html` и доступна после запуска проекта.

## Общие элементы

- **Шапка:** логотип Red Corner, навигация по публичным разделам, кнопки входа или выхода.
- **Область контента:** карточки, формы и таблицы текущего раздела.
- **Футер:** название проекта, API health-check и ссылки на разделы.
- **Состояния:** динамические блоки показывают `Загрузка...`, данные или сообщение `Ошибка`.
- **Источник:** карточки и списки получают данные через API, API читает записи из MySQL.

## 1. Главная `/`

**Тип доступа:** публичный.

**Основные блоки:**

1. Шапка и навигация.
2. Hero-блок «Liverpool FC» с переходами к матчам и новостям.
3. Секция «Ближайшие матчи»: карточки соперников, дата, турнир, счёт.
4. Секция «Последние новости»: заголовок, категория, дата, изображение.
5. Футер.

**Динамический контент:** блоки 3-4, `GET /api/matches` и `GET /api/news` -> MySQL.

## 2. Аутентификация `/auth/login`, `/auth/register`, `/auth/forgot-password`

**Тип доступа:** публичный.

**Основные блоки:** форма email и пароля; форма регистрации с именем и секретным словом; форма восстановления пароля; сообщения валидации; ссылка на соседнее состояние формы.

**Динамический контент:** `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/forgot-password` -> `users`.

## 3. Матчи `/matches`

**Тип доступа:** публичный.

**Основные блоки:** заголовок, строка поиска, фильтр турнира, сортировка, сетка карточек матчей, кнопки «В избранное» и «Купить билет» для авторизованного пользователя.

**Динамический контент:** `GET /api/matches?search=&championship=&sort=` -> `matches`.

## 4. Команды `/teams`

**Тип доступа:** публичный.

**Основные блоки:** сетка карточек команд, герб/изображение, страна, стадион, краткое описание, раскрываемая зона состава.

**Динамический контент:** `GET /api/teams`, `GET /api/teams/:id/roster` -> `teams`.

## 5. Новости `/news`

**Тип доступа:** публичный.

**Основные блоки:** заголовок раздела, карточки публикаций, изображение, категория, дата, текст новости.

**Динамический контент:** `GET /api/news` -> `news`.

## 6. Детали команды `/teams/:id`

**Тип доступа:** публичный.

**Основные блоки:** крупная карточка команды, герб, страна, стадион, описание, список игроков, кнопка возврата в каталог.

**Динамический контент:** `GET /api/teams/:id/roster` -> `teams.roster`.

## 7. Личный кабинет `/profile`

**Тип доступа:** приватный.

**Основные блоки:** имя, email, роль, дата регистрации; форма изменения имени; форма смены пароля; список купленных билетов.

**Динамический контент:** `GET/PUT /api/auth/me`, `GET /api/tickets` -> `users`, `tickets`, `matches`.

## 8. Избранное `/favorites`

**Тип доступа:** приватный.

**Основные блоки:** заголовок, список сохранённых матчей, дата и соперник, удаление из избранного, переход к покупке билета.

**Динамический контент:** `GET /api/favorites`, `DELETE /api/favorites/:matchId` -> `favorites`, `matches`.

## 9. Билеты `/tickets`

**Тип доступа:** приватный.

**Основные блоки:** карточки электронных билетов, уникальный код, матч, дата, стоимость, дата покупки.

**Динамический контент:** `GET /api/tickets`, `POST /api/tickets/:matchId` -> `tickets`, `matches`.

## 10. Админ-панель `/admin`

**Тип доступа:** приватный, только роль `admin`.

**Основные блоки:** вкладки пользователи, матчи, команды и новости; формы создания/редактирования; таблицы записей; удаление; загрузка изображения.

**Динамический контент:** `GET /api/users`, CRUD `/api/matches`, CRUD `/api/teams`, CRUD `/api/news`, `POST /api/uploads` -> соответствующие таблицы MySQL.

## Состояния экрана «Матчи»

| Состояние | Схематичное содержимое | Условие |
| --- | --- | --- |
| Загрузка | Заголовок + три серых скелетона карточек + текст `Загрузка матчей...` | Запрос `GET /api/matches` ещё не завершён |
| Данные | Фильтры + карточки «Ливерпуль — Арсенал», дата, турнир, действия | API вернул HTTP 200 и массив матчей |
| Ошибка | Заголовок «Не удалось загрузить матчи» + текст ошибки + кнопка повторить | API вернул ошибку или MySQL недоступен |

## Состояния форм аутентификации

- **Начальное:** пустые поля и кнопка действия.
- **Загрузка:** кнопка заблокирована, текст `Выполняется вход...`.
- **Успех:** сообщение о входе, сохранение JWT и переход на главную.
- **Ошибка:** красное сообщение под формой, введённые данные остаются на экране.
